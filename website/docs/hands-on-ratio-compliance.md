## Hands-On Ratio Calculation Method

### Definition of Hands-On Content
1. **Interactive Elements**: Any content requiring student interaction
   - Code execution in browser
   - Simulation manipulation
   - Parameter adjustment
   - Result observation

2. **Practical Exercises**: Activities with measurable outcomes
   - Step-by-step implementations
   - Problem-solving tasks
   - Experimentation activities
   - Project components

3. **Application Activities**: Content requiring active participation
   - Code modification exercises
   - System configuration tasks
   - Testing and validation
   - Troubleshooting activities

### Definition of Theory Content
1. **Conceptual Explanations**: Background information
   - Technical concepts
   - Architecture overviews
   - Design principles
   - Best practices

2. **Reference Materials**: Informational content
   - API documentation
   - Configuration guides
   - Troubleshooting guides
   - Resource references
